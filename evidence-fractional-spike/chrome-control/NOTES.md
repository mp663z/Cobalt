# Chrome control, fractional font sizes (UNREVIEWED measurement; no engine change)
Chrome 156.0.8078.47 headless, DPR 1, script ctl.mjs, page.html. Fonts bound by @font-face from file:// (sha256 in font-sha256.txt); document.fonts reports status loaded for LibCtl and DejaCtl, 0 for the nonexistent family.
Binding caveat: the unbound fallback family renders IDENTICAL numbers to LibCtl, so for Liberation Serif the numbers alone do not prove the bound file was used (the fallback is evidently the same face or metric-identical); only document.fonts status does. DejaCtl differs from fallback, so that row set is distinguishable.
Rows are layout rects (getBoundingClientRect), not rasters. They say nothing about glyph raster, subpixel origin or shaping. Observed only: Chrome widths here are multiples of 1/64 (e.g. 9.390625); that is an observation on these rows, not an adopted contract. Chrome block height with line-height normal is an integer and differs from fontdue new_line_size at several sizes (see compare.txt). No cause is claimed.
