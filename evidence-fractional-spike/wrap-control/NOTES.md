# Wrap control (UNREVIEWED measurement)
Chrome 156.0.8078.47, embedded pinned faces, kerning and ligatures disabled in Chrome (font-kerning:none, kern/liga off), a 25-word ASCII paragraph, 17 authored sizes k/64 px (12..24, k step 47) x 23 container widths (exact 1/64 multiples, 120..420) x 3 faces = 1173 cases. Chrome break positions read from word span tops; model = greedy wrap over fontdue unrounded advance sums (space included, word fits if <= width).
Result: identical break sets in 1156/1173 (98.6%), different in 17: Liberation Serif 1/391, DejaVu 7/391, Liberation Sans 9/391; the number of lines differs in 5 of the 17. Differences occur at integer sizes too (Liberation Sans 12 px at width 160.109375). Direction is not consistent (model breaks earlier or later). Cause not established (candidates: word measured as separate shaping units, rounding of the width comparison); not tested.
Meaning: any claim of Chrome line-break equality must carry about 1.4% case-level flip observed in this grid; a flip moves later lines and page height. This is a measured approximation, not an exact geometry contract.
